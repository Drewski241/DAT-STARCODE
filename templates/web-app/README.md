# Web app starter (DAT STARCODER)

Minimal static starter the agent can extend. Prefer editing in place.

## Run

Open `index.html` in a browser, or serve the folder with any static server.

## When fixing errors

Paste the full `npm run build` / `npm run dev` / browser console output and ask **Fix this**.
The worker classifies the error, edits the cited file, and re-runs the command.
